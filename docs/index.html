⚡ Sandık açma nasıl çalışır?

  1. Tarama: GitHub Actions her 5 dakikada bir yayınları tarar, sandıkları kaydeder.
  2. Bildirim: Web paneli ve Windows ajanı sandığı anında listeler; Telegram/Discord uyarısı gider.
  3. Açma: Windows ajanı açılışa 20 sn kala yayını tarayıcıda açar (AUTO_JOIN=1).
  4. Katılım: Açılan yayında tek dokunuşla katıl; jeton cüzdanına düşer.

Dürüst sınır: Sandık açma asistanı yalnızca yayını açar ve bildirir; jeton toplamaz. TikTok zarf/jeton toplama mobil oturum ister; sistem hesabına giriş yapmaz ve senin yerine talep göndermez.

🖥️ Windows kurulum paketi

GitHub Actions her sürümde ArenaLiveOS-Setup-*.exe üretir. Kurulumdan sonra panel http://localhost:3000 adresinde açılır; ajan arka planda çalışır.

  • Açılışta GitHub manifest kontrolü (sha256) → değişen dosyalar otomatik iner
  • Çalışırken 30 dakikada bir güncelleme kontrolü
  • Sandık verisi 3 sn'de bir; sayaç saniyelik
  • Yerel hızlı durum: http://localhost:4780
